# Fishing

**Play it: https://cauwenberghscasper-maker.github.io/Fishing/** (phone or desktop browser; add `?test=100` for fast test mode)

A 3D fishing adventure on a chain of islands, with an idle economy underneath. Angled top-down camera, mobile first, runs in the browser.

- Design, art direction and rules: [`docs/MASTER_PROMPT.md`](docs/MASTER_PROMPT.md)
- How the systems connect: [`docs/INTERFACES.md`](docs/INTERFACES.md)
- Licences and credits: [`CREDITS.md`](CREDITS.md)

## Run locally
```
npm install
npm run dev
```
Add `?test=100` for fast test mode.
